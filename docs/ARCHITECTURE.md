## Voice Mode Loop

`/voice` toggles a background `@work(exclusive=False)` worker (`_run_voice_loop`)
that runs alongside the normal `_generate_response` worker. All audio I/O is
blocking and offloaded via `asyncio.to_thread` so the Textual event loop never
stalls. Everything is local — no network calls.

```mermaid
flowchart TD
    V["/voice (typed)"]
    H["_handle_voice()"]
    On["voice OFF → ON:<br/>create VoiceEngine (lazy)<br/>create threading.Event<br/>start _run_voice_loop() as background worker"]
    Off["voice ON → OFF:<br/>set _voice_stop_event"]
    Loop["_run_voice_loop()<br/>(while self._voice_active)"]
    Mount["mount '🎙 Listening…'"]
    Rec["engine.record(stop_event)"]
    StopRet["return None<br/>(stop_event.set() mid-recording,<br/>checked every audio frame)"]
    Widget["remove listening widget"]
    Res{"audio_path or None"}
    Trans["engine.transcribe(audio_path)<br/>(faster-whisper)"]
    Msg["_handle_user_message(text)"]
    Pipe["normal chat pipeline<br/>(_generate_response, tool loop)"]
    Poll["poll self.agent.generating until False"]
    Speak["engine.speak(last_assistant_message)<br/>(Piper TTS)"]

    V --> H
    H -->|"voice OFF → ON"| On
    H -->|"voice ON → OFF"| Off
    On --> Loop
    Off -.->|"interrupts recording"| Rec
    Loop --> Mount
    Mount --> Widget
    Mount --> Rec
    Rec --> StopRet
    Rec --> Res
    StopRet --> Res
    Res -->|"None (silence) → loop back"| Loop
    Res -->|audio_path| Trans
    Widget --> Trans
    Trans --> Msg
    Msg --> Pipe
    Pipe --> Poll
    Poll --> Speak
    Speak -->|"loop back to Listening… if still active"| Loop
```

Key points:

- **Immediate interruption** — `VoiceEngine.record()` polls the shared
  `threading.Event` every audio frame, so toggling `/voice` off during an
  in-progress recording returns `None` right away instead of waiting out the
  silence/max-duration timeout (`SILENCE_TIMEOUT_MS` / `MAX_RECORD_SECONDS`).
- **Shares the normal pipeline** — transcribed text is fed through
  `_handle_user_message`, so tool calls, permission prompts, and session
  persistence all behave exactly as they do for typed input.
- **Lazy model loading** — `VoiceEngine.load()` (Whisper, Piper, WebRTC VAD)
  only runs on first activation, keeping TUI startup fast.
- **Also stopped on app exit** — `on_unmount` clears `_voice_active` and sets
  the stop event so a lingering recording doesn't block shutdown.

## Tool Execution Flow

```mermaid
flowchart TD
    GenCall["Agent generates tool call:<br/>{'tool': 'builtin__read_file',<br/>'parameters': {'file_path': '/path/to/file.txt'}}"]
    Dispatch["tools/manager.py<br/>Dispatch to handler"]
    LoadH["Load handler module"]
    Exists{"Exists?"}
    ErrNF["Return error<br/>'Tool not found'"]
    Perm["Permission Check<br/>- Profile allows tool?<br/>- Session grant exists?<br/>- Tool-level checks pass?"]
    ErrPerm["Return error<br/>'Permission denied'"]
    Val["Validate Parameters<br/>- Schema validation<br/>- Type checking<br/>- Required fields"]
    ErrVal["Return error<br/>'Invalid parameters'"]
    Run["Execute Tool Function<br/>- Run implementation<br/>- Capture output<br/>- Handle errors"]
    Fmt["Format Result<br/>- Convert to string<br/>- Truncate if needed<br/>- Sanitize sensitive data"]
    Ret(["Return result to Agent"])

    GenCall --> Dispatch
    Dispatch --> Exists
    Dispatch --> LoadH
    Exists -->|Yes| Perm
    Exists -->|No| ErrNF
    Perm -->|Allowed| Val
    Perm -->|Denied| ErrPerm
    Val -->|Valid| Run
    Val -->|Invalid| ErrVal
    Run --> Fmt --> Ret
```

## Useful Architecture Patterns

| Pattern             | Usage                | Location         |
| ------------------- | -------------------- | ---------------- |
| **Factory**         | Backend creation     | backend.py       |
| **Strategy**        | Tool implementations | tools/\*.py      |
| **Observer**        | Textual events       | views.py         |
| **Builder**         | Config precedence    | settings.py      |
| **Adapter**         | Backend interface    | backends/        |
| **Registry**        | Tool management      | tools/manager.py |
| **Template Method** | Agent processing     | agent.py         |
